# Changelog

## 1.5.0

- **Больше не нужен YTVideoOverlay:** YouVOT сам добавляет кнопку в плеер. Ставится одним пакетом.
- Положение кнопки (сверху или снизу, рядом с полноэкранным режимом) выбирается в настройках YouVOT → «Кнопки».
  Если раньше кнопка была перенесена вниз через YTVideoOverlay, это сохранится.
- В сборках, где YTVideoOverlay всё же есть, кнопка YouVOT не перекрывает его кнопки.

Установка: встройте `com.dragoy.youvot_1.5.0_iphoneos-arm64.deb` в свой IPA YouTube или соберите IPA
через *Actions → Build IPA*. На джейлбрейке: `iphoneos-arm64` — rootless, `iphoneos-arm` — rootful.

## 1.4.0

Первый публичный релиз.

- Закадровый перевод видео YouTube от Яндекса на русский, английский или казахский, синхронно с плеером
  (перемотка, пауза, скорость, реклама); оригинал приглушается под перевод.
- **Мой язык:** видео на вашем языке не переводятся. Язык речи определяется сам — по аудиодорожке,
  автосубтитрам YouTube или названию.
- **Автоперевод** только при надёжно определённом языке; список языков, которые не нужно переводить;
  отдельный переключатель для Shorts (по умолчанию выключен).
- **Тип озвучки:** обычная или живые голоса (на русский), со входом в аккаунт Яндекса.
- Для видео, которые Яндекс ещё не переводил, YouVOT сам отправляет аудиодорожку.
- Кнопка в плеере: нажатие — настройки (первая строка включает перевод этого видео),
  долгое нажатие — включить / выключить. Своя кнопка на экране Shorts.
- Раздел «Закадровый перевод» в настройках YouTube и журнал перевода для диагностики.

Установка: встройте `com.dragoy.youvot_1.4.0_iphoneos-arm64.deb` и `com.ps.ytvideooverlay_*_iphoneos-arm64.deb`
(оба лежат в этом релизе) в свой IPA YouTube, либо соберите IPA через *Actions → Build IPA*.
На джейлбрейке: `iphoneos-arm64` — rootless, `iphoneos-arm` — rootful.
